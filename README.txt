ENDER UNIVERSAL ENCHANTS BEDROCK BEHAVIOR PACK

Install:
1. Put the folder containing manifest.json into the behavior_packs folder.
2. Activate Ender Universal Enchants in the world's Behavior Packs screen.
3. Enable Beta APIs / experiments if your Minecraft version asks for them.
4. Re-enter the world.

Enchanting table:
- The normal enchanting-table screen is disabled.
- Interact with an enchanting table while at level 5 or higher.
- The pack charges the first payment you can afford:
  32 lapis lazuli, or 16 iron ingots, or 8 emeralds.
- Five experience levels are consumed.
- You receive one random enchanted book.

Universal enchant command:
- Hold any item and run:
  /scriptevent ender:enchant <enchantment> [level]
- Level defaults to the normal maximum and is limited to 255.
- Run this to see all supported names:
  /scriptevent ender:list
- The command requires at least 5 experience levels, but does not consume them.
- Compatible enchantments become real Bedrock enchantments. Incompatible item combinations are recorded in the item's lore so any item can receive any listed enchantment.

Supported names include:
aqua_affinity, bane_of_arthropods, blast_protection, channeling, depth_strider, efficiency, feather_falling, fire_aspect, fire_protection, flame, fortune, frost_walker, impaling, infinity, knockback, looting, loyalty, luck_of_the_sea, lure, mending, multishot, piercing, power, projectile_protection, protection, punch, quick_charge, respiration, riptide, sharpness, silk_touch, smite, soul_speed, sweeping_edge, swift_sneak, thorns, unbreaking.
